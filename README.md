# 💰 Daily Expenses Bot — Telegram-бот для учёта личных финансов

Telegram-бот на Python (aiogram 3) для учёта доходов и расходов. Операции можно писать обычным текстом («такси 25 сом») или наговаривать голосовым сообщением. Бот сам определяет сумму, валюту и категорию, ведёт бюджеты, регулярные платежи и строит отчёты.

## Возможности

- **Ввод обычным текстом.** Парсер извлекает сумму, валюту (TJS, RUB, USD) и категорию. Если категория неочевидна, бот предлагает выбрать её кнопками и запоминает выбор (таблица `learned_keywords`).
- **Голосовой ввод.** Голосовое сообщение конвертируется через `ffmpeg`, распознаётся локально моделью `faster-whisper` (`small`) и обрабатывается как обычный текст.
- **Мультивалютность.** Сумма пересчитывается в базовую валюту пользователя и хранится вместе с курсом на момент операции. Курсы обновляются ежедневно в 00:05 (основной источник `open.er-api.com`, запасной — Frankfurter).
- **Бюджеты по категориям.** Предупреждения при достижении 80% и 100% месячного лимита.
- **Регулярные платежи.** Ежедневные, еженедельные и ежемесячные списания, проверка каждые 10 минут.
- **Отчёты.** За день, неделю и месяц, круговые диаграммы matplotlib, экспорт в Excel (`.xlsx`).
- **Отмена.** Операцию можно отменить в течение 10 минут после добавления.
- **Вечернее напоминание** в 21:00.
- **Четыре языка интерфейса:** русский, английский, таджикский, узбекский.
- **Админ-панель** для владельца бота (доступ по `ADMIN_TELEGRAM_ID`).

## Стек

- Python 3.11+, aiogram 3
- PostgreSQL, SQLAlchemy 2 (asyncio) + asyncpg
- Alembic — миграции
- APScheduler — курсы валют, регулярные платежи, напоминания
- matplotlib, pandas, openpyxl — отчёты и Excel
- httpx — запросы курсов
- faster-whisper + ffmpeg — голосовой ввод
- rapidfuzz — нечёткое сопоставление слов
- pytest, pytest-asyncio — тесты

## Установка и запуск

Нужны Python 3.11+, PostgreSQL и `ffmpeg` (для голосовых сообщений).

```bash
git clone https://github.com/firdavsjons/daily_expenses_bot.git
cd daily_expenses_bot

python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

cp .env.example .env
```

Заполните `.env`:

```env
POSTGRES_USER=postgres
POSTGRES_PASSWORD=your_postgres_password
POSTGRES_HOST=localhost
POSTGRES_PORT=5432
POSTGRES_DB=expenses_bot
TELEGRAM_BOT_TOKEN=your_telegram_bot_token
DEFAULT_CURRENCY=TJS
ADMIN_TELEGRAM_ID=0
```

Токен выдаёт [@BotFather](https://t.me/BotFather). `ADMIN_TELEGRAM_ID` — ваш числовой Telegram ID для доступа к админ-панели; значение `0` отключает админ-панель. Файл `.env` не попадает в Git.

Применение миграций и запуск:

```bash
alembic upgrade head      # бот также сам создаёт базу при первом запуске
python3 -m bot.main
```

## Как это работает

1. **Парсер** (`bot/parser.py`) находит сумму, определяет валюту по ключевым словам (`сом`, `руб`, `$` и т. д.) и сопоставляет слова с категориями, включая выученные слова пользователя. Остаток текста уходит в комментарий.
2. **Курсы валют** обновляются планировщиком APScheduler и сохраняются в базе. Каждая операция хранит сумму в базовой валюте пользователя.
3. **Бюджеты:** после каждого расхода бот сравнивает траты за месяц с лимитом категории и отправляет предупреждение.
4. **Регулярные платежи** обрабатываются фоновой задачей и создают операции автоматически.
